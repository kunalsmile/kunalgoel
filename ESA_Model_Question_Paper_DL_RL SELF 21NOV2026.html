Vanishing Gradient: It occurs when gradients become extremely small during backpropagation in deep neural networks. As a result, earlier layers learn very slowly.

How Batch Normalization helps:

  1. Normalizes inputs to each layer.
  2. Maintains stable data distribution.
  3. Improves training speed.
  4. Makes learning more stable. Remember: Vanishing Gradient = Very small gradients; Batch Normalization = Stable and faster training.

Gate Function

  1. Sigmoid vs ReLU

Sigmoid: σ(x) = 1 / (1 + e⁻ˣ), output in (0, 1). ReLU: f(x) = max(0, x), output in [0, ∞).

Aspect Sigmoid ReLU Gradient Max 0.25; near 0 for large |x| (saturates) 1 for x > 0, 0 for x < 0 Output centering Not zero-centered Not zero-centered, but sparse Compute cost Expensive (exponential) Very cheap Main issue Vanishing gradients "Dying ReLU" (neurons stuck at 0)

Preference:

ReLU (or variants like Leaky ReLU, GELU) for hidden layers in deep networks. It trains faster, gives sparse activations, and avoids saturation for positive inputs. Sigmoid at the output layer for binary classification (the output is interpreted as a probability), and in gating mechanisms (e.g., LSTM gates) where a 0-1 range is needed. 2. Vanishing Gradient Problem and Batch Normalization

Vanishing gradients: During backpropagation, gradients are computed by the chain rule as products of many per-layer derivatives. If these derivatives are less than 1 (e.g., sigmoid/tanh in saturated regions, or small weights), the product shrinks exponentially with depth. Early layers receive near-zero gradients, so they learn extremely slowly or not at all.

How Batch Norm helps: BatchNorm normalizes each layer's pre-activations to zero mean and unit variance per mini-batch, then applies learnable scale (γ) and shift (β):

x̂ = (x − μ_B) / √(σ²_B + ε), y = γx̂ + β

It keeps inputs to activations in the non-saturating region (e.g., near the steep center of sigmoid/tanh), so derivatives don't collapse. It stabilizes the distribution of layer inputs (reducing internal covariate shift), preventing activation scales from drifting and gradients from shrinking or exploding. It makes training less sensitive to weight initialization and allows higher learning rates. 3. The Three Gates in an LSTM Cell Forget gate (fₜ): Decides what information from the previous cell state Cₜ₋₁ to discard (values near 0 = forget, near 1 = keep). Input gate (iₜ): Decides which parts of the new candidate values (C̃ₜ) to write into the cell state. Output gate (oₜ): Decides which parts of the (tanh-squashed) cell state are exposed as the hidden state hₜ, i.e., the output at this step. 4. Bellman Optimality Equation for Q(s,a) $$Q^(s,a) = \sum_{s',r} p(s',r \mid s,a)\left[r + \gamma \max_{a'} Q^*(s',a')\right]$$

Equivalently, in expectation form:

$$Q^*(s,a) = \mathbb{E}\left[R_{t+1} + \gamma \max_{a'} Q^*(S_{t+1}, a') \mid S_t = s, A_t = a\right]$$

where γ ∈ [0, 1] is the discount factor. This is the basis of Q-learning.

  1. Exploration vs Exploitation

The dilemma: An agent must choose between exploiting what it already knows to get high reward now, and exploring unfamiliar actions that might yield better long-term reward but risk lower immediate payoff. Too much exploitation can trap the agent in a suboptimal policy; too much exploration wastes reward.

Analogy: Choosing where to eat dinner. You have a favorite restaurant you know is good (exploit). But a new place opened nearby that could be even better, or could be disappointing (explore). If you always go to your favorite, you may never discover a better option; if you always try new places, you often end up with mediocre meals.

Common strategies: ε-greedy (explore with probability ε, often decayed over time), Upper Confidence Bound (UCB), Thompson sampling, and softmax/Boltzmann exploration.

5.6 Three LSTM Gates The LSTM architecture contains three gates.

Formula: [ o_t=\sigma(W_o[h_{t-1},x_t]+b_o) ]

[ P(\text{Exploit})=1-\epsilon ]

Example:

If epsilon = 0.3:

  • 30% chance of selecting random action.
  • 70% chance of selecting best-known action. Algorithm
  1. Generate random number between 0 and 1.
  2. Compare it with epsilon.
  3. If random number is less than epsilon, select random action.
  4. Otherwise, select action with highest estimated value.
  5. Observe reward.
  6. Update action value. 7.13 Epsilon Decay Epsilon decay gradually reduces exploration.

Example: [ \epsilon_{new}=\max(\epsilon_{min},\epsilon\times decay) ]

Suppose:

  • Initial epsilon = 1.0.
  • Decay = 0.995.
  • Minimum epsilon = 0.01. As training continues, exploration decreases. Imagine a machine with multiple arms, each producing a different reward distribution.

The agent must decide which arm to select to maximize reward.

Example: Arm Average Reward A 5 B 8 C 3

The agent should explore the arms and gradually identify the most rewarding one. Sample Average Method The estimated value of an action is calculated by averaging rewards received from that action. [ Q_t(a)= \frac{\text{Sum of rewards from action }a} {\text{Number of times action }a\text{ was selected}} ]

The lecture also discusses limitations of storing all previous rewards and recalculating averages.

9.10 Policy Gradient Policy Gradient is a reinforcement learning approach that directly optimizes the policy.

Unlike Q-Learning, which learns action values, Policy Gradient adjusts policy parameters to increase expected cumulative reward. Policy Types A. Deterministic Policy [ a=\pi(s) ]

The policy selects a specific action for a given state.

B. Stochastic Policy [ a\sim\pi(\cdot|s) ]

The policy assigns probabilities to different actions. Neural Network Output For discrete actions:

  • Uses Softmax.
  • Produces action probabilities. For continuous actions:
  • Can output Gaussian mean and variance.
  • Samples an action from the Gaussian distribution. 9.11 Policy Gradient Objective The objective is to find policy parameters that maximize expected cumulative reward. [ J(\theta)=E_{\tau\sim\pi_\theta} \left[\sum_t r_t\right] ]

Where:

  • (\theta) = Policy parameters.
  • (\tau) = Trajectory.
  • (\pi_\theta) = Parameterized policy.
  • (r_t) = Reward. Basic idea:
  • If an action generates high reward, increase its probability.
  • If an action generates poor reward, reduce its probability. 9.12 Gradient Ascent Policy Gradient uses gradient ascent to maximize expected reward. [ \theta\leftarrow\theta+ \alpha\nabla_\theta J(\theta) ]

Difference:

  • Gradient Descent minimizes loss.
  • Gradient Ascent maximizes objective/reward. Policy Gradient Theorem The simplified expression in the lecture is: [ \nabla_\theta J(\theta)= E\left[ \sum_t \nabla_\theta\log\pi_\theta(a_t|s_t) G_t \right] ]

Explanation:

  1. Calculate gradient of log action probability.
  2. Calculate return.
  3. Multiply the gradient by return.
  4. Update policy parameters. Higher returns encourage the policy to repeat successful actions. 9.13 REINFORCE Algorithm REINFORCE is a Monte Carlo Policy Gradient algorithm.

It directly updates the policy using returns obtained from complete trajectories. Steps

  1. Initialize policy network with random parameters.
  2. Generate an episode using the current policy.
  3. Record states, actions and rewards.
  4. Calculate return for each time step.
  5. Calculate policy gradients.
  6. Update parameters.
  7. Repeat for multiple episodes. Return Formula [ G_t=\sum_{k=t}^{T}\gamma^{k-t}r_k ]

Policy Update [ \theta\leftarrow\theta+ \alpha\sum_t \left[ \nabla_\theta\log\pi_\theta(a_t|s_t)G_t \right] ]

Practical Implementation Action Type Policy Output Discrete Softmax probabilities Continuous Gaussian distribution

The negative sign converts the reward-maximization objective into a loss-minimization objective. 9.14 Policy Gradient – CartPole Example Consider CartPole.

S1: Introduction to Neural Networks (and TensorFlow/Keras) Neural network basics Artificial neural networks are computing systems inspired by biological neurons. The activation function defines a node's output given its input. Examples are sigmoid, tanh, ReLU and the binary step function. Output ranges: Sigmoid gives (0, 1). Tanh gives (-1, 1). ReLU gives (0, max). Feed-forward network layers: Input layer: One node per input dimension. Hidden layers: Take weighted inputs and produce output through an activation. Output layer: Represents the network's output. Training process Decide the network structure. Create the network. Choose hyperparameters. Calculate the loss. Reduce the loss. Repeat steps 4 and 5. Loss and optimization Loss (error) is the difference between actual and predicted values, and the goal is to minimize it. The loss function is chosen per problem, and classification and regression use different ones. Optimization means finding the weights that reduce loss. The gradient is the change in loss per change in weights. Weights are updated using the gradient, repeating until a minimum is reached. Gradient descent variants Variant Gradient computed over Batch Whole dataset Stochastic (SGD) Each single training example Mini-batch Each batch of n examples (a mix of the two above) Backpropagation, learning rate and momentum Backpropagation: Used in feed-forward training. Momentum: Weights contributions from previous iterations. It speeds training and helps avoid local minima. Summary of the NN process

Neurons are connected and each has an activation. Training learns weights and biases through forward propagation, then loss computation, then backpropagation. Backprop continues layer by layer until each neuron receives a loss signal showing its contribution.

S2: Building Blocks Refresher Feed-forward: One-directional flow from input to output, with no intra-layer connections. Loss: The predicted output is compared with the actual output, and the difference (loss) determines how to adjust weights. Backpropagation: Computes the error gradient for all weights and biases, from the output layer backward. A new forward pass should then give lower error. Feed-forward as a composition of functions

Each layer applies weights plus an activation, and the network is the composition of these layers.

Backpropagation and the chain rule The core quantity is the partial derivative of the loss with respect to each weight. It applies the chain rule layer by layer, using Jacobians: Element (k, l) of the weight Jacobian says how much the k-th output changes when the l-th weight changes. Element (k, l) of the input Jacobian says how much the k-th output changes when the l-th input to that layer changes. Gradients are propagated backward by multiplying by each layer's Jacobian. Forward propagation (FPROP) and backward propagation (BPROP) are "duals" of each other. Fully connected layers Every neuron connects to all activations in the previous layer, so connections grow quickly. The forward pass is one matrix multiplication, a bias offset, then an activation. For example, Linear(5,4) has a 4×5 weight matrix. The backward pass uses a 4×5 Jacobian for the inputs and a 4×20 Jacobian for the weights. Activation functions Activations apply a non-linearity, which allows non-linear decision boundaries. They act like a gate that switches a neuron on or off. Function Notes Sigmoid f(x) = 1/(1+e⁻ˣ), range 0–1. Not zero-centered, suffers vanishing gradients, converges slowly. tanh Range -1 to 1, zero-centered, easier to optimize, but still suffers vanishing gradients. ReLU Simple and very efficient with much better convergence. Not zero-centered and used only in hidden layers. Can "die", with neurons that never activate again. Leaky ReLU / PReLU A small negative-side slope keeps neurons alive. It does not saturate on the positive side.

In practice: Prefer ReLU and watch the learning rate and the fraction of dead units. Try Leaky ReLU or Maxout, never use sigmoid, and try tanh (usually worse than ReLU).

Vanishing and exploding gradients

Gradients involve many repeated factors of W and the activations. If the largest singular value of the matrices is above 1, gradients explode. If it is below 1, they vanish. This is a geometric series that goes to 0 or infinity.

Softmax It is a multinomial logistic classifier, usually the last layer of a classifier. It exponentiates the scores, then normalizes them into probabilities. Worked example: scores 3.15, 5.3, -2.1 become probabilities 0.104, 0.895 and 0.00. Cross-entropy loss Also called log loss. It measures unhappiness with the predicted distribution versus the desired output. Loss is Lᵢ = -ln(probability of the correct class). With p = 0.104 this gives 2.26, and a perfect prediction gives 0. Gradient descent reduces this loss for classification. S3: Fine-Tuning Your Neural Network Weight initialization All zeros: Effect: Every weight gets the same gradient and the same update. Hidden units stay symmetric forever, so the network is no better than a linear model. Random init: When it works: Small networks, such as a two-layer MNIST classifier. When it fails: Deep networks, where it causes vanishing or exploding gradients. Vanishing: |dW| shrinks going backward, early layers train slowest, and training may stall completely. Exploding: Large weights cause oscillation or overshooting of the minimum, number overflow, and NaN losses. Best practices: Use ReLU or Leaky ReLU, and use Xavier initialization (random values that are not too small or too large). Initialization remains an active research area, with Glorot & Bengio 2010, He et al. 2015 (for ReLU) and others. Batch normalization Core idea: Normalize each layer's inputs to zero mean and unit variance, so each layer's input distribution stays stable whatever happens upstream. Formula: x̂ = (x − E[x]) / σ, followed by scale (γ) and shift (β), which are learnable: y = γx̂ + β. Why γ and β are needed: Linear regime: Normalized inputs sit in the nearly linear region of sigmoid and tanh. ReLU: Half of the inputs are zeroed. Result: The network can learn to move or squash the distribution. Benefits: Faster training, better gradient flow, higher learning rates, less dependence on initialization, and mild regularization. Test time: It uses fixed running averages of mean and standard deviation, not batch statistics. It can be applied before or after the non-linearity. Dropout How it works: Randomly set some neurons to zero in each training forward pass. Purpose: Prevent overfitting. Fully connected layers hold most parameters, so neurons become co-dependent, and dropout forces redundant representations. A cat-detector example makes the point: features like ears and tail must each work independently. At test time: All neurons are on, and activations are scaled so expected output matches training. Choosing architecture and hyperparameters Start simple, for example a single-layer network (784 MNIST inputs to 10 output classes). Hyperparameters to tune: architecture, learning rate and its schedule, and regularization strength (L2 or dropout). Monitor loss and accuracy curves: Big train/validation gap: Overfitting, so increase regularization. No gap but low accuracy on both: Increase model capacity. S4a: Working with Time-Series Data Forecasting It is important in economics, business, environmental science, medicine and politics. It reduces the effect of risk and uncertainty. It supports marketing, production planning and inventory control, new product launches, and finance and risk. Qualitative methods are subjective (market surveys, expert opinion). Quantitative methods are objective (regression, time-series models). Regression recap It is illustrated with an ice-cream store: temperature versus sales. R² is the share of variation in the target explained by the predictors. It never decreases when variables are added. Adjusted R² rises only when added variables are significant and may fall otherwise. If R² and adjusted R² are close, there are probably no unnecessary predictors. What is a time series? It is a sequence of measurements on the same variable at equally spaced intervals. An example is quarterly retail turnover from 1982 Q3 to 1992 Q1. Univariate: One variable, such as room temperature every minute. Multivariate: Several variables over the same period, such as unemployment, GDP and inflation. Typical intervals: Yearly: GDP. Quarterly: Revenue. Monthly: Sales. Weekly: Fuel price. Daily: Stock close. Hourly: Air quality. What is not a time series: Irregular intervals: Data at unequal times (mixed yearly and quarterly data, or earthquakes). Cross-sectional data: Many items at a single time point (Dow Jones stocks on one day). Applications: Power demand, finance, aviation pricing, hotel pricing, production planning. The defining feature Order matters and observations are not independent. Shuffling cross-sectional data (cars, MPG) changes nothing, but shuffling a time series destroys its structure. Missing values: Time series do not admit gaps. Impute them. First step: Always plot the series. Components Systematic component (interpretable and estimable): Trend: Long-term increase or decrease. Seasonality: Stable intra-year fluctuations that repeat each year in timing, direction and magnitude. A yearly series has none. Irregular component (error or white noise): The unexplained remainder, assumed normal with mean 0 and constant variance σ². Seasonality example: Yearly sales of 400, so a quarterly average of 100. Actual sales of 80, 70, 200 and 50 give seasonal estimates of -20, -30, +100 and -50. Decomposition Why decompose: To de-seasonalize a series, compare trend versus seasonal influence, and compare sectors with different seasonality. Additive model: Seasonal swings are constant. The example is average monthly temperature, where the seasonal indices sum to 0 (January -9.24, July +12.73). Multiplicative model: Seasonal swings scale with the level. The example is airline passengers, where the highest volume is in July and August. Moving average

Average over a sliding window, moving it forward to update. A longer window (MA-30 vs MA-5 on Tesla stock) gives a smoother trend.

Module scope

Smoothing methods, ARMA, ARIMA for non-stationary and seasonal data, and multivariate forecasting.

S4b: Recurrent Neural Networks Sequential data A sequence is x = (x₁, …, x_T), and order carries meaning. Examples: Text ("The cat chased the mouse" ≠ "The mouse chased the cat"), time series (stocks, ECG), audio (44,100 samples/s), video frames, and biological sequences (DNA, proteins). Characteristics: Importance of order: Position determines interpretation. Short-term dependencies: Adjacent words influence each other. Long-term dependencies: A verb can depend on a distant subject. Variable length: Sequences differ in length, which is awkward for batching. Why feed-forward networks fail They treat each input independently and have no mechanism to retain past inputs. Forecasting tomorrow's temperature needs previous days. Models need memory, an internal state updated as inputs arrive. Other approaches to sequence modeling Memoryless: Autoregressive models (fixed delay taps) and feed-forward nets. They have limited windows and cannot use hidden state efficiently. Memoryful: Linear dynamical systems (real-valued hidden state) and HMMs (discrete hidden state, stochastic transitions). They are costly to infer. RNN advantages: State: Distributed hidden state stores much past information efficiently. Dynamics: Non-linear dynamics, deterministic updates (no inference needed), and weight sharing. RNN structure Definition: A neural network with feedback connections. It has input X, hidden state S and output O, with weights U, V and W. Hidden state: hₜ = tanh(Wₓxₜ + W_h·hₜ₋₁ + b), and the output is yₜ = W_y·hₜ + b. It acts as short-term memory. Weight sharing: The same weights are reused at every step, so it handles variable-length input. Unrolling: Expands the recurrence over time steps, like a deep network across time. Example: A character-level language model with vocabulary [h, e, l, o] as one-hot vectors. Forward pass: The same as an MLP with one hidden layer, except hidden activations also come from the previous time step. Backpropagation Through Time (BPTT) The error for a sequence is the sum of errors at each step. It is the chain rule applied across time, accumulating gradients for U, V and W. It is efficient in compute but not in memory. Full algorithm: forward pass computing hₜ, yₜ and Lₜ, then a backward pass from T down to 1. Then accumulate ∂L/∂W_xh, W_hh and W_hy, and update by gradient descent. Configurations

Many-to-one (sentiment analysis), one-to-many (image captioning), many-to-many (machine translation) and language modeling.

Problems Long-term dependencies: Example 1 is "sky" depending on "clouds" (3 steps apart). Example 2 is "Hindi" depending on "India" (9 steps apart). Vanishing gradients: Small weights make the gradient shrink exponentially and learning stops. Exploding gradients: Large weights make it grow exponentially and weights become unstable. Extensions and time-series preparation Extensions: Bidirectional and deep bidirectional RNNs. Time-series preparation: Check characteristics and stationarity or trend, use sliding windows to create supervised data, and use temporal train-test splits (no shuffling across time). S5: LSTM Networks Motivation RNNs suffer vanishing and exploding gradients and effectively have only short-term memory. On a paragraph they cannot carry early information to later steps. Solution: Gates control what to keep and what to throw out. LSTM and GRU both use gates internally. LSTMs let the network forget unimportant information and store important information in the cell state. They made higher-quality text predictions than RNNs and were the de facto NLP architecture before Transformers. Architecture Cell state (Cₜ): The horizontal "conveyor belt" through the cell and the long-term memory. It carries information across time steps without vanishing. Hidden state (hₜ): Separate short-term memory, also the cell's output. The dual long/short-term memory is the key improvement over the RNN. A vanilla RNN cell has a single tanh layer. An LSTM cell has four interacting layers: three sigmoids and one tanh. The three gates Gate Role Equation Forget How much old memory to forget fₜ = σ(W_f·[hₜ₋₁, xₜ] + b_f) Input How much new information to memorize iₜ = σ(W_i·[hₜ₋₁, xₜ] + b_i), with candidate C̃ₜ = tanh(W_C·[hₜ₋₁, xₜ] + b_C) Output How much to pass to the next unit oₜ = σ(W_o·[hₜ₋₁, xₜ] + b_o) Cell update: Cₜ = fₜ ∗ Cₜ₋₁ + iₜ ∗ C̃ₜ Hidden state: hₜ = oₜ ∗ tanh(Cₜ) GRU (Gated Recurrent Unit) A simplified, newer variant. No separate cell state. The hidden state carries information. Two gates: Update gate: Combines the LSTM's forget and input gates. Reset gate: Decides how much past information to forget. Fewer tensor operations make it faster than LSTM. Supervised learning learns from (x, y) pairs. Unsupervised learning finds structure in x alone. RL is more general: the agent receives rewards or penalties and must discover good actions by trial and error. It is "the science of decision making". Analogies: Training a dog with food rewards, a baby learning to walk, and the "teach the cat" example about how the state is defined. RL process: Observe, decide, act, receive reward, learn, iterate. Core components Agent: The learner and decision-maker. It starts without knowing the rules. Environment: Everything external. It maintains the state, responds to actions, generates rewards, and may be stochastic. Interaction loop: The environment is in state sₜ. The agent selects aₜ. The environment returns rₜ₊₁ and sₜ₊₁. The agent updates and repeats. State: It should contain all information needed for decisions. In a fully observable (Markov) setting, like chess, the current state suffices. Partial observability, like poker, needs memory. Agent state and environment state can differ. Action: Discrete (left/right, buy/sell/hold) or continuous (steering angle, torque). Reward: Nature: A scalar feedback signal, immediate and designed by humans. It is the only learning signal. Objective: The goal is to maximize cumulative reward, not just immediate reward. Chess is the example, where sacrificing pieces enables checkmate. Reward hypothesis: All goals can be described as maximizing expected cumulative reward. Reward design: Good: Robot walking gets +1 for forward progress and -1 for falling. Bad: +1 for any movement makes the robot spin in circles, and +1 for speed makes the car drive dangerously. Policy: The agent's behavior, deterministic or stochastic. Model: The agent's representation of the environment. It has a transition model (predicts the next state) and a reward model (predicts immediate reward). Episode: One complete interaction from the initial to a terminal state, then reset. Episodic tasks have an end (games, CartPole, mazes). Continuing tasks don't (stock trading, factory control). CartPole walkthrough State: [cart position, cart velocity, pole angle, pole angular velocity]. Actions: 0 is push left and 1 is push right. Reward: +1 per step the pole stays up. Episode ends when: The pole angle exceeds 12°. The cart position exceeds 2.4. 500 steps are reached. "Solved": Average 195+ over 100 consecutive episodes. Learning progression: Early: 10–30 steps per episode. Middle: 50–150 steps. Trained: 200–500 steps. Difficulty: Continuous state, small changes matter, delayed consequences, and the need to balance both angle and position. Tractability: Only 2 actions, deterministic physics, immediate reward and a clear success metric. Return and discounting Return: Gₜ = Rₜ₊₁ + Rₜ₊₂ + Rₜ₊₃ + … (total future reward). Problems with undiscounted return: It can be infinite for infinite episodes, treats future and immediate rewards equally, and learning can be unstable. Discounted return: Gₜ = Σ γᵏ·Rₜ₊ₖ₊₁ with 0 ≤ γ ≤ 1. Why discount: It models time preference, keeps the return finite, and stabilizes learning. A small γ gives a reactive agent and a large γ a strategic one. Applications, advantages and limits Applications: Domains: Robotics, games (AlphaGo, Atari DQN), autonomous vehicles, NLP, manufacturing, education, e-commerce (recommendation, dynamic pricing) and telecom. Environment need: Getting started needs simulated environments, which is why OpenAI Gym exists. Advantages: It solves problems conventional techniques can't, learns from direct interaction, handles non-deterministic environments, and combines with deep learning. Limits: Data and compute: It needs lots of data and compute. Reward dependence: It depends heavily on reward quality. Optimality and fit: It gives no guarantee of the maximum, is overkill for simple problems, and is hard to debug and interpret. S7: Markov Decision Processes and Value Functions Markov property The future depends only on the current state, not on the history. The current state carries all relevant information. Markov states: Chess position, grid cell, CartPole (position and velocity). Non-Markov states: Cart position without velocity, stock price without history, partial sensor readings. The transition probability function gives the probability of s′ given s and a. MDP definition An MDP is the tuple (S, A, P, R, γ): S: States. A: Actions. P: Transition probabilities. R: Reward function. γ: Discount factor. MDP vs RL: Solving an MDP: An offline process where the dynamics are known. RL: Online, with no prior knowledge of the dynamics. The agent learns from experience. Why MDPs: They model sequential decisions with uncertain outcomes and delayed rewards. Policy: A mapping from states to actions, deterministic or stochastic. Value functions V(s): Expected long-term return from state s under policy π. In GridWorld, states near the goal have high V and trap states have low V. Q(s,a): The value of taking action a in state s. Action-value estimation (bandit view) Sample-average method: Qₜ(a) is the average of rewards received when a was chosen. It converges to q(a) as Nₜ(a) → ∞, with unvisited actions initialized (often to 0). The issue is that storing all rewards needs growing memory and compute. Greedy: Always pick the highest estimate. It is pure exploitation, with no exploration, so it gets stuck in suboptimal solutions. Constant step size (nonstationary problems): Use a fixed α for exponential recency-weighted averages. Benefits: Quick adaptation and simplicity. Drawback: Estimates never fully converge and may oscillate. Exploration vs exploitation Exploration: Gathering information about the environment. Exploitation: Using the best-known option. Analogies: Restaurant (favorite dish vs new dish), trekking, movie recommendation, store location, chess moves. Why balance: Only exploiting gets stuck, and only exploring never maximizes reward. Netflix example: A largely greedy/exploit policy that recommends the title the model predicts you'll watch. ε-greedy: Rule: With probability ε pick a random action, otherwise pick the best-known one (with ε decayed over time: more exploration early, more exploitation later). Guarantee: Every action is sampled infinitely often, so Q converges to q. Weakness: It treats all non-greedy actions equally, ignoring near-optimal or uncertain ones. Bellman equations Principle: How good I am now = reward now + discounted value of the future. State value: V(s) = immediate reward + γ·V(next state). Action value: Q(s,a) = reward + γ·value of next state. Grid example: Step reward -1, goal value +10, γ = 0.9 gives V = -1 + 0.9×10 = 8. Why it matters: It breaks long-term reward into incremental steps and is the foundation of value iteration, Q-learning and DQN. S8: Q-Learning Algorithm Model-based vs model-free Model-based: Builds a model of the environment and plans by simulating outcomes (chess AI, weather models). Model-free: Learns directly from experience (Pong, robot arm learning). Temporal-Difference (TD) learning Core idea: A model-free method that adjusts predictions toward later, better predictions before the final outcome is known. It is a combination of Monte Carlo (updates only after the episode ends) and Dynamic Programming (bootstrapping). Bootstrapping: Updating estimates from other estimates. TD error: The gap between the target (r + γV(s′)) and the current estimate V(s). Advantages: Learning mode: Online updates every step, sample-efficient, and works in continuing tasks. Statistics: Lower variance than MC and good in stochastic settings. Speed and requirements: Faster convergence, and no model needed. TD(0): V(s) ← V(s) + α[r + γV(s′) − V(s)]. TD(λ) adds eligibility traces and spans between TD(0) and MC. Batch updating: TD(0): Converges to the solution consistent with the Markov structure (Bellman consistency). MC: Converges to the solution minimizing error against the observed returns. Result: TD uses limited data more efficiently. SARSA (on-policy TD control) Named for the sequence State, Action, Reward, State, Action. Update: Q(s,a) ← Q(s,a) + α[r + γQ(s′,a′) − Q(s,a)], where a′ is the action actually taken. It learns the value of the same policy it follows. It is simple and converges if all pairs are visited infinitely often and α decays. Windy GridWorld example: Setup: Wind in some columns pushes the agent up. Reward is -1 per step and 0 at the goal. Policy: ε-greedy. Result: The agent learns to compensate for the wind and find the shortest path. Q-learning (off-policy TD control) Update: Q(s,a) ← Q(s,a) + α[r + γ·maxₐ′Q(s′,a′) − Q(s,a)]. It uses the greedy max over next actions regardless of the action actually taken, so it learns the optimal policy while behaving ε-greedily. Properties: Model-free, off-policy, and converges to optimal Q with enough exploration and a decaying learning rate. Cliff Walking example: Setup: A 4×12 grid where the bottom row is a cliff. Stepping in gives -100 and resets, and other steps give -1. Comparison: Contrasted with SARSA. Expected SARSA

Replaces Q(s′,a′) with the expectation over next actions under the current policy. This gives lower variance, more stability and policy-aware updates.

Maximization bias and Double Q-learning Maximization bias: Using the max of noisy estimates overestimates values. The same samples are used both to choose and to evaluate the action. This leads to inflated Q-values, suboptimal policies and slower convergence. Double learning: Maintain two Q-tables, one to select the action and the other to evaluate it. This reduces overestimation and gives more reliable policies in stochastic settings. S9: Policy Gradients, Deep Q-Learning & Applications Limits of tabular RL Curse of dimensionality: Storage: States = (values per feature)^(features). Ten features × ten values gives 10¹⁰ states. Sample efficiency: Most states are never visited, so generalization is impossible. Continuous spaces: Robot joints and driving states can't be discretized without losing precision or exploding the state count. Memory: A Q-table has |S|×|A| entries. A million states and 10 actions give 10 million entries. Continuous spaces: Discretization loses precision, needs manual bin selection, and grows exponentially. CartPole's continuous observations make a Q-table fail. Function approximation Replace the Q-table with a parameterized function Q(s,a;θ), a neural network, trained to minimize Q-value prediction error. Benefits: Generalization across similar states, a compact representation (thousands of parameters for millions of states), and handling of continuous inputs. Network design: Input is the state, hidden layers extract features, and the output is Q(s,a₁)…Q(s,aₙ). For CartPole the input is 4 numbers and the output is Q(left) and Q(right). From Q-learning to DQN Tabular update recap: Q(s,a) ← Q(s,a) + α[r + γ·maxₐ′Q(s′,a′) − Q(s,a)]. DQN loss: L(θ) = E[(r + γ·maxₐ′Q(s′,a′;θ⁻) − Q(s,a;θ))²], an MSE between target and prediction, optimized with gradient descent. Why it is not standard supervised learning: Moving target: The target depends on the network itself. Correlated data: Sequential data is highly correlated. Shifting distribution: The data distribution changes as the policy improves.

Fix 1: Target network

Keep an online network θ (updated every step, used for action selection) and a target network θ⁻ (used only for targets). Copy θ⁻ ← θ every C steps (e.g., 1,000). Fixed targets give stable training and less divergence.

Fix 2: Experience replay buffer

Store (s, a, r, s′, done) in a fixed-size buffer (e.g., 100,000), dropping the oldest when full. Sample random minibatches (e.g., 32). This breaks correlations and reuses data. A Pong example shows consecutive "losing" states biasing the network.

DQN algorithm:

Initialize the buffer, online network and target network. For each step: Select an action ε-greedily. Execute it and observe r and s′. Store the transition. Sample a minibatch. Compute targets yⱼ = rⱼ + γ(1−doneⱼ)·maxₐ′Q(s′ⱼ,a′;θ⁻). Update θ by gradient descent on (yⱼ − Q(sⱼ,aⱼ;θ))². Every C steps set θ⁻ ← θ.

Key hyperparameters: Buffer 10k–1M, minibatch 32–256, target update every 1,000–10,000 steps, ε from 1.0 decaying to 0.01.

Atari architecture: Input is 4 stacked 84×84 grayscale frames (to capture motion). It has conv 32 filters 8×8 stride 4, conv 64 filters 4×4 stride 2, conv 64 filters 3×3 stride 1, flatten, a dense 512 layer, then |A| outputs. It has about 1–2 million weights.

Policy gradient basics Value-based (Q-learning/DQN): Learn Q or V, with an implicit greedy policy π(s) = argmaxₐQ(s,a). The limitation is that this policy is deterministic. Policy-based: Learn π(a|s;θ) directly with no explicit value function. The policy can be stochastic. Why stochastic policies: Rock-paper-scissors: The optimal strategy is 1/3 each, and any deterministic policy can be exploited. Robot grasping: Small variations aid exploration and robustness. Representation: Deterministic a = π(s), stochastic a ~ π(·|s). The network outputs softmax probabilities for discrete actions or a Gaussian mean and variance for continuous ones. Policy gradient objective and theorem Objective: J(θ) = E_τ~π_θ[Σ rₜ], the expected cumulative reward over trajectories. Intuition: Increase the probability of actions that led to high reward and decrease it for those that led to low reward. Update: θ ← θ + α∇_θJ(θ). Policy Gradient Theorem (simplified): ∇_θJ(θ) = E[Σₜ ∇_θ log π_θ(aₜ|sₜ) · Gₜ] Log-probability term: The direction that raises the probability of the action taken. Return term: Weights that direction by how good the outcome was. REINFORCE (Monte Carlo policy gradient) Initialize the policy network. Sample a full trajectory with the current policy. Compute returns Gₜ = Σₖ₌ₜᵀ γ^(k−t)·rₖ. Update θ ← θ + α Σₜ ∇log π(aₜ|sₜ)·Gₜ.

The practical loss is L(θ) = −Σₜ log π_θ(aₜ|sₜ)·Gₜ. The CartPole example shows an episode lasting 50 steps (G₀ = 50), which makes the actions taken in that episode more likely.

Advantages of policy gradients Continuous action spaces: They sample from N(μ, σ). Q-learning needs discretization or tricks such as DDPG. Stochastic policies: They give natural exploration, whereas value methods need ε-greedy. Convergence: Policy gradients converge to a local optimum and give smoother updates, while Q-learning with function approximation can diverge. High-dimensional actions: There is no need to evaluate Q for every action. Just sample. Limitations High variance: Returns vary wildly. Fixes are baselines and advantage functions (A2C, PPO). Sample inefficiency: They are on-policy, so each trajectory is used once and a replay buffer can't be used directly. Hyperparameter sensitivity: Too high a learning rate causes policy collapse, and too low is slow. Trust-region methods (TRPO, PPO) help. Credit assignment: Deciding which actions were responsible for the reward. Hands-on
